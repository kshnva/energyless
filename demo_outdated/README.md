# WorkflowAware Scheduler Demo

(OUTDATED: PLEASE READ [SETUP_GUIDE](../SETUP_GUIDE.md) for running actual experiments)

The files in this directory display the properties of our coded "WorkflowAware" scheduler.
You can run any of the demo notebooks:

1. [demo_1.ipynb](./demo_1.ipynb) - shows how `WorkflowAware` scheduler prioritizes critical paths of workflow DAG's
2. [demo_2.ipynb](./demo_2.ipynb) - shows how `WorkflowAware` scheduler prioritizes workflows with shorter deadlines.
3. [demo_3.ipynb](./demo_3.ipynb) - shows how `WorkflowAware` performs in multi-workflow workload and how it shortens the execution time.
